# 任务:在 macOS 上构建 rscat 的安装包(.pkg)

你在 macOS 机器上。请把 Rust 命令行工具 rscat 打成 macOS 安装包,双架构(x86_64 + arm64)。

## 项目源码

源码在 Linux 机器的 `/home/terminal/Documents/Projects/rscat/`(纯 Rust 项目,无 C 依赖)。
先把整个目录同步过来(git clone / scp / rsync 均可,排除 target/ 和 build/)。
若无法同步:源码就 10 个文件,见下方"源码清单",手工重建亦可行。

## 构建步骤

```bash
# 1. 工具链(Rust 1.70+)
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y
source "$HOME/.cargo/env"

# 2. 双架构构建
cd rscat
cargo build --release --target aarch64-apple-darwin
cargo build --release --target x86_64-apple-darwin

# 3. 合并 universal binary(可选,推荐)
lipo -create \
  target/aarch64-apple-darwin/release/rscat \
  target/x86_64-apple-darwin/release/rscat \
  -output rscat-universal

# 4. 打 .pkg 安装包(装到 /usr/local/bin)
mkdir -p pkgroot/usr/local/bin pkgroot/usr/local/share/rscat/shells
cp rscat-universal pkgroot/usr/local/bin/rscat        # 或分架构两个包
cp shells/* pkgroot/usr/local/share/rscat/shells/
pkgbuild --root pkgroot --identifier mo.terminal.rscat \
         --version 1.1.4 --install-location / rscat-core.pkg
productbuild --package rscat-core.pkg rscat-1.1.4-6-macos.pkg
```

## 交付物(放到项目 build/macos/ 目录)

- `rscat-1.1.4-6-macos-aarch64.pkg`(Apple Silicon)
- `rscat-1.1.4-6-macos-x86_64.pkg`(Intel)
- (可选)`rscat-1.1.4-6-macos-universal.pkg`

## 验收标准

1. `pkgutil --expand-full` 能展开;`lipo -info` 报告正确架构。
2. 安装后 `/usr/local/bin/rscat --version` 输出 `rscat 1.1.4-6`;`rscat -h` 正常。
3. `echo hello | rscat -f` 输出彩虹色(不带 -f 时非 tty 会原样直通,属正常)。
4. 在 iTerm2/WezTerm 里 `rscat 某图片.png` 能显示图片(--proto iterm 自动)。

## 已知行为(不是 bug)

- 过滤模式在 stdout 非 tty 且未加 `-f` 时原样直通(与 lolcat 一致)。
- `-e`(pty 运行模式)和 `-a`(会话)用的是 POSIX pty,macOS 上应可直接工作;
  若有问题请报告,不必修。
- 代码只用了 libc 的通用 POSIX 接口(posix_openpt/fork/execvp 等),没有
  Linux 专属调用。
